Abenezer Basaznew - 3D Portfolio Website

HOW TO OPEN
1. Extract this folder.
2. Double-click index.html (Chrome or Edge). An internet connection is needed
   because the 3D library (three.js) and the fonts load from the web.

FILES
index.html            the whole website: HTML, CSS, JavaScript, 3D scene, embedded photo
assets/original-photo.jpg   your original photo (a smaller copy is already inside index.html)

HOW TO EDIT (open index.html in VS Code)
- Work page: search for  id="p3"  and replace the text with your real projects.
- Contact details: search for  id="p4".
- Skills: search for  id="p2".
- Colors: search for  :root{  at the top of the <style> section.

HOW TO PUT IT ONLINE (free)
Upload the folder to Netlify Drop (app.netlify.com/drop), GitHub Pages or Vercel.
